# SOC Investigation Case Reports

A practical cybersecurity portfolio documenting hands-on SOC, threat detection, incident response, malware analysis, and digital forensics investigations.

## About This Repository

This repository contains structured case reports based on cybersecurity labs, simulated incidents, and hands-on security exercises.

The objective is to demonstrate practical SOC Analyst skills, including:

- Security event analysis and alert triage
- SIEM investigation using KQL and SPL
- Windows Event Logs and Sysmon analysis
- Phishing and malware investigation
- Process and network activity correlation
- Incident classification and escalation
- MITRE ATT&CK mapping
- Incident documentation and reporting

## Investigation Methodology

Each case report aims to document:

1. Incident overview
2. Alert details and initial assessment
3. Evidence collection
4. Technical investigation
5. Event correlation and timeline
6. Indicators of Compromise (IoCs), where applicable
7. MITRE ATT&CK mapping, where applicable
8. Findings and impact assessment
9. Incident classification
10. Recommended containment and remediation
11. Evidence limitations and final conclusion
